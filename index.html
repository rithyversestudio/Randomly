About Randomly

Randomly is a free random number generator from RithyVerse Studio. You choose a minimum and a maximum, pick a reveal style (a spinning wheel, a mystery crate, a number machine or a card draw), and the site shows you a random whole number from your range. It works with any range from 1 to 1,000,000.

How the numbers are generated

Every number is generated in your own browser using the Web Crypto API (crypto.getRandomValues). To keep results fair, Randomly uses rejection sampling, so each whole number in your range, including both endpoints, has exactly the same chance of being picked. Nothing you enter is sent to a server.

How Random Number Generators Work

A random number generator (RNG) is a tool that picks a number without any pattern you could predict. They are used everywhere, from picking who goes first in a game to creating test data for software.

Pseudo-random vs. cryptographic randomness

Most programming languages offer a basic generator that follows a mathematical formula. These are called pseudo-random generators: fast and good enough for many games, but in principle predictable if you know the starting value. Browsers also provide a cryptographic generator that draws on unpredictable system sources such as hardware timing noise. Randomly uses this stronger source.

Why fairness matters

A common mistake is to take a large random value and use the remainder after dividing by the range size. This slightly favors some numbers. Randomly avoids that bias by discarding values that would cause it and drawing again, so every whole number in your range, including both endpoints, is equally likely.

Common uses

  • Classrooms: choosing a student, assigning groups or practising probability.
  • Games: picking a secret number, deciding turn order or settling a tie.
  • Decisions: number your options and let a draw choose.
  • Testing: creating sample values for software tests.

Common myths

Random does not mean evenly spread. Getting the same number twice in a row is perfectly normal, and a number that has not appeared in a while is not "due". Each draw is independent of the last.
